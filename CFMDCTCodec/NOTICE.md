# Notice

This repository contains an implementation of CFMDCTCodec for low-bitrate
speech coding experiments.

The implementation reuses common neural audio codec components and includes
code adapted from or inspired by the following open-source projects and papers:

- HiFi-GAN discriminator and utility patterns.
- ConvNeXt-style temporal blocks.
- Diffusers transformer blocks for the conditional flow matching decoder.
- Vector-quantization techniques from VQ/VQGAN-style codecs.

Before public release, please verify that the intended release license is
compatible with all third-party code, model weights, and training data used in
your released artifacts.
